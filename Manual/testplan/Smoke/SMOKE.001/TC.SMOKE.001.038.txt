[Expected]

  • CKEditor JavaScript loads with HTTP 200.
  • The rich-text editor toolbar (bold, italic, list, link, etc.) is
    present and the editor accepts text input.

[Actual — open bug K8]

    broken: the CKEditor JS bundle returns 404:
      /bundles/fosckeditor/ckeditor.js?v3.0.11
  • Console shows uncaught reference errors where CKEDITOR.replace is
    called against a missing global.
  • User cannot edit T&C content.

[Notes]

    blocked — affects compliance workflow).

    exists on the asset server).
  • When K8 is fixed, the page-smokes.spec.ts test.fail() marker for
    TC.SMOKE.001.038 should be removed AND a follow-up test added that
    verifies the CKEditor toolbar renders + accepts input.
