# =============================================================================
# Consentz Web App — Manual Test Case Template (per sub-feature)
# =============================================================================
# Convention: ONE manual file per sub-feature, holding detailed reproduction
# steps for every TC in that sub-feature. The hierarchical TC ID's middle
# segment (TC.<MODULE>.<SUB>.<NNN>) defines the sub-feature; the file name
# is `TC.<MODULE>.<SUB>.txt`.
#
# Example: testplan/dashboard/manual/TC.DASH.001.txt covers all 41 cases
# under Dashboard's Time Period Filter sub-feature (TC.DASH.001.001 through
# TC.DASH.001.041).
#
# This is preferred over one-file-per-TC because it:
#   - keeps related cases together (shared preconditions stated once)
#   - reduces clutter (9 files per page module instead of ~270)
#   - makes review easier — open one file to see every scenario for the
#     sub-feature
# =============================================================================
